# 🛍️ E-Commerce Web Application

A full-stack e-commerce web application developed during my software development internship. The project provides a platform where customers can browse products, manage their shopping cart, place orders, review products, and communicate with sellers.

## 🚀 Features

* 👤 User registration and login
* 🔐 Customer and seller roles
* 🛍️ Product listing and product details
* ➕ Adding and managing products
* 🛒 Shopping cart management
* 📦 Order management
* 💬 Instant messaging between sellers and customers
* 👤 User profile management
* 🔎 Product search
* ⭐ Product reviews and ratings

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/USERNAME/REPOSITORY-NAME.git
cd REPOSITORY-NAME
```

### 2. Run the Backend

```bash
cd backend
dotnet restore
dotnet run
```

### 3. Run the Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

The frontend will run on:

```text
http://localhost:5173
```

The backend API will run on:

```text
http://localhost:5070
```

## 🗄️ Database

The project uses two databases:

* **PostgreSQL** for users, products, carts, orders, and order items.
* **MongoDB** for instant messaging and reviews.

Database connection settings should be configured before running the application.

## 🎯 Project Purpose

The main goal of this project is to gain practical experience in full-stack web development and to build a real-world e-commerce application using modern web technologies.
The project focuses on creating a user-friendly shopping experience while implementing both customer and seller functionalities.
